A plugin to restrict block usage based on user roles.

== Description ==

Easily manage and restrict access to WordPress editor blocks based on user roles. Choose which blocks each role can see in the block editor, keeping the inserter focused for editors and contributors while administrators keep the full set.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install the zip from Plugins > Add New.
2. Activate it through the Plugins screen.
3. Configure it from the plugin's settings screen where one exists.
